# Senthilkumar KS — Portfolio

A responsive personal portfolio for an aspiring Cloud & DevOps Engineer.

## Files
- `index.html` — portfolio website
- `style.css` — responsive styling

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `style.css`.
3. In repository Settings → Pages, choose the main branch and root folder.
4. GitHub will provide your live portfolio URL.
